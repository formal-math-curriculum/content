# Third-party payload notices

No third-party taxonomy payload is vendored in this bootstrap.

- MSC 2020 remains `license_needs_review`; repository CC0 does not relicense it.
- OntoMathPRO 2.0 has no selected authoritative payload.
- arXiv taxonomy metadata has no downloaded snapshot in this bootstrap.

Future payloads require an exact source, version/retrieval date, checksum, license,
attribution, adapter version, and reviewed payload state.
